# Hailey Heiwig Nails

Multi-page website for Hailey Heiwig’s custom nail art, press-on drops, and influencer presence.

## Pages
- `index.html` — Homepage with hero and featured work
- `gallery.html` — Full gallery of work
- `shop.html` — Press-on shop section with product cards
- `services.html` — Custom sets, press-ons, and collaborations
- `about.html` — Artist story and emotional positioning
- `contact.html` — Inquiry form for products, custom work, and sponsorships

## Features
- Clean multi-page structure with consistent navigation
- Press-on shop with product placeholders and inquiry links
- Gallery and about sections focused on wearable art and identity
- Contact form (Formspree-ready) that can pre-select inquiry type
- Social media link placeholders

## Setup
1. Enable GitHub Pages: Settings → Pages → Deploy from branch `main` / root.
2. Replace placeholder images with Hailey’s actual photos.
3. Update social media links across pages.
4. Replace `YOUR_FORM_ID` in contact forms with a real Formspree ID (or switch form service).
5. Adjust pricing, product details, and copy as needed.

Live site (once Pages is enabled): `https://dlhiwig.github.io/hailey-heiwig-nails/`
