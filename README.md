# Hailey Heiwig Nails

Website for Hailey Heiwig’s custom nail art, press-on drops, and influencer presence.

## Features
- Gallery of work (replace placeholder images with Hailey’s photos)
- About section with emotional positioning (wearable art & identity)
- Services: Custom sets, Press-ons, Collaborations/Sponsorships
- Contact form for product requests, custom inquiries, and sponsorships
- Social media links (update with real accounts)

## Setup
1. Enable GitHub Pages in repo Settings → Pages → Deploy from branch `main` / root.
2. Replace placeholder images in `index.html` with Hailey’s actual work.
3. Update social media links in the Contact section.
4. Set up Formspree (or another form service) and replace `YOUR_FORM_ID` in the form action.
5. Customize colors, copy, and details as needed.

## Emotional Core
Wearable art that supports self-expression and confidence.

Live site will be available at: `https://dlhiwig.github.io/hailey-heiwig-nails/` once Pages is enabled.
